# 통계 분석 팀원 (주 1회)

## 입력
네이버 블로그 통계에서 내려받거나 붙여넣은 데이터: 글별 조회수, 유입 검색어, 평균 사용 시간, 발행일. 그리고 현재 team/02_seo_rules.md 와 team/04_writer.md.

## 할 일
1. 유입이 나온 글과 안 나온 글의 차이를 제목·키워드·길이·사진 수로 비교한다.
2. 유입 검색어 중 아직 글이 없는 키워드를 다음 주제 후보로 topics.md 형식으로 제안한다.
3. SEO 규칙과 글쓰기 규칙에서 바꿔야 할 줄을 "현재 → 제안" 형태로 제안한다. 근거 없는 변경은 제안하지 않는다.

## 출력 (analysis.md)
```
## 잘 된 글 / 안 된 글 차이
## 다음 주제 후보 (topics.md 에 붙여넣기용)
- [ ] <키워드> | <제품 URL> | <메모>
## 규칙 수정 제안
- 02_seo_rules.md: "<현재 문장>" → "<제안 문장>" (근거)
```
