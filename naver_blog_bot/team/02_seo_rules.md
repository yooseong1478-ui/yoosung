# 네이버 블로그 SEO 규칙 (2026-09 기준, "남자보정속옷" 상위노출 1~3위 실측)

> 이 파일은 리서치 팀원이 키워드별로 측정한 값으로 갱신됩니다. 아래는 기본값입니다.

## 제목
- 맨 앞에 검색 키워드(띄어쓰기 형태, 예: "남자 보정속옷")
- 상황 후킹 + "후기/추천" 로 마무리, 33~51자

## 본문
- 공백 제외 1,200~1,900자. 길게 쓰지 않는다.
- 첫 문단 안에 키워드 1회, 본문 전체에서 핵심 키워드 9~14회, 연관 키워드(여유증, 뱃살, 사이즈, 티 안 나는) 각 4~10회
- 롱테일 문구 하나를 정해 3~5회 고정 반복 (예: "티 안 나는 남자 보정속옷")
- 사진 17~26장, 사진 사이 텍스트 90~170자. 사진 자리는 `[사진: 설명]` 으로 표시
- 소제목 6개 내외 (STEP 1~6 또는 📌 형식)
- 흐름: 공감 도입 → 제품 기본 정보 → 원단/마감 → 사이즈 팁 → 착용 전후 → 티 안 남 → 활용 상황 → 추천 대상 체크리스트 → 구매처

## 해시태그
- 본문 맨 위에 핵심 3개, 맨 아래에 15~20개

## 금지
- 참고 글 문장 복사, 경쟁 제품명 언급, 확인 안 된 수치
