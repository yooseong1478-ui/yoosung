네이버 블로그 자동화 새 창으로 크게 열기

로그인 → 글감 찾기 → 글 쓰기 → 발행. 각 단계는 버튼 한 번이면 됩니다.

1 네이버 로그인 확인 중

버튼을 누르면 아래에 로그인 화면이 열립니다. 그 화면에서 네이버 아이디와 비밀번호로 로그인하세요. "새로운 기기" 인증 문자가 오면 거기서 입력하면 됩니다. 한 번만 하면 저장됩니다.

2 글 올리기

올릴 글을 고르고 버튼을 누르면 사이트가 네이버 에디터에 글과 이미지를 넣어 줍니다. 임시저장은 네이버 "임시저장 글"에 들어가고, 발행은 바로 공개됩니다. 직접 찍은 사진 자리는 "(사진 넣기: …)" 로 들어가니 임시저장 후 채우는 것을 권합니다.

고급 기능 열기 (글감 찾기 · AI 글쓰기 · Claude 연결)

1 네이버 로그인 확인 중

버튼을 누르면 로그인 창이 뜹니다. 로그인하면 창이 자동으로 닫히고 세션이 이 PC에 저장됩니다.

클라우드에서 실행 중이라 로그인 창이 원격 화면에 뜹니다.

1 Claude 연결 확인 중

글쓰기 단계가 Claude 구독으로 동작합니다. 시작 → 링크 열어 승인 → 나온 코드를 붙여넣기.

1) 이 링크를 열어 로그인하고 승인하기

2 글감 찾기

3 글 쓰기

모은 인기 글의 패턴(제목, 길이, 사진 수, 키워드)을 분석해 내 제품 기준으로 새 글을 쓰고, 정보성 이미지는 슬라이드로 만듭니다.

또는 이미 만들어 둔 글을 바로 불러오기

4 발행

임시저장은 네이버 임시저장 목록에 넣고 멈춥니다. 직접 찍은 사진을 넣은 뒤 발행하는 것을 권장합니다.
