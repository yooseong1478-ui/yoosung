# 지난 글이 상위노출되지 않은 이유와 v2 보완 (2026-09-17 실측)

## 지난 글 (basicfassion 블로그, "남자보정속옷 뉴슬림엑스, 뱃살 보정·사이즈 선택 가이드")
- "뉴슬림엑스" 검색 블로그탭 4위·6위에는 뜨지만 "남자보정속옷" 상위 30개 안에 없음.
- 형식: 제품 설명 정리 글. 본문에 "직접 착용한 후기 사진은 아닙니다" 고지. 이미지 6장 전부 공식몰 이미지.
- 문장: PC용 긴 문장 단락. 소제목 있음. 착용 전/후, 개봉, 라벨, 겉옷 위 착용 컷 없음.

## 상위 1~3위 글은 어떻게 다른가
| 항목 | 지난 글 | 상위 1~3위 |
|---|---|---|
| 형식 | 제품 소개 | 1인칭 체험 후기 (STEP 소제목, 체크리스트) |
| 이미지 수 | 6 | 16~25 |
| 이미지 종류 | 공식 이미지만 | 실사 위주: 개봉·패키지, 옷걸이 컷, 원단 클로즈업, 라벨, 착용 전/후(사진 위 글자), 흰 티·셔츠 위 가슴/옆구리 클로즈업, 옆모습, 마무리 착용 컷 + 공식 일러스트 1~2장 |
| 구성 요소 | 텍스트+이미지 | 이미지 스트립(2~3장 나란히), 이미지 그룹, 짧은 동영상(2·3위), 구매 링크 카드, 인용구, 스티커 |
| 글자 수(공백 제외) | 약 1,800 | 1,229 / 1,854 / 1,253 |
| 문장 | 긴 단락 | 한 줄 15~25자, 2~4줄마다 빈 줄 |
| 제목 | 키워드 + 쉼표 + 가이드 | 키워드 맨 앞 + 상황 후킹 + 후기/추천 |

핵심 원인은 두 가지다. (1) 검색 의도가 "후기"인데 글이 "소개"였고, (2) 이미지가 공식몰 재사용 6장뿐이라 경험 문서로 평가받기 어려웠다.
발행 직후라면 색인 시간도 필요하지만, 형식 차이가 더 크다.
